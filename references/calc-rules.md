# กติกาคำนวณเงินเดือน (รายชั่วโมง / Part-time)

ทุกข้อในไฟล์นี้ตรงกับ `assets/template/Code.gs` และถูกตรวจโดย `scripts/test-core.js` (24 เคส)

## ชั่วโมงต่อแถว — `calcRowHours_(row)`
1. ถ้าแถวมี `normal_hours` หรือ `ot_hours` > 0 → **เชื่อตามที่กรอก** ไม่คำนวณจากเวลา
2. ไม่งั้นคำนวณจาก `check_in`/`check_out` (รับ `9:00`, `09:00`, `9.00`)
   - `worked = (ออก − เข้า − พัก) / 60`
   - พัก = `break_minutes` ของแถว ถ้าเป็น 0/ว่าง → `default_break_minutes` (ค่าตั้งต้น 60)
   - `normal = min(worked, standard_day_hours)` (ตั้งต้น 8)
   - `extra = worked − standard_day_hours` → เป็น OT **ต่อเมื่อ `extra ≥ ot_min_minutes/60`**
3. ออก ≤ เข้า → 0 ชั่วโมง (กะข้ามเที่ยงคืน **ยังไม่รองรับ** — ขึ้นคำเตือน "เวลาออก ≤ เวลาเข้า")

ตัวอย่าง: 09:00–18:30 พัก 60 → worked 8.5 → ปกติ 8, OT 0.5

## อัตราค่าแรง
- ค่าแรงปกติ = `Employees.hourly_rate`
- OT/ชม. = `Employees.ot_rate` ถ้า > 0, ไม่งั้น `hourly_rate × ot_multiplier` (ตั้งต้น 1.5)

## ต่อคนต่องวด — `calcPayroll_({from, to, onlyApproved})`
```
normal_pay = Σnormal × hourly_rate
ot_pay     = Σot × ot_rate
gross      = normal_pay + ot_pay + diligence(เบี้ยขยัน) + addition(เงินเพิ่ม) + bonus
total_deduct = wht(ภาษีหัก ณ ที่จ่าย) + deduction(หักอื่น)
net        = gross − total_deduct
```
- เงินเพิ่ม/หักมาจากชีต Adjustments แถวที่ `employee_id|period_from|period_to` ตรงกับงวดที่คำนวณ **เป๊ะ**
  → เปลี่ยนช่วงวันที่ของงวด = ปรับเงินที่กรอกไว้ไม่ถูกดึงมา
- `onlyApproved: true` นับเฉพาะแถว `อนุมัติแล้ว` — หน้าคำนวณควรเปิดให้เลือก และสลิปจริงควรใช้ true
- `days` = จำนวนวันที่ไม่ซ้ำ · `work_time` = ช่วงเข้า-ออกที่ทำบ่อยสุด ("09:00 – 18:30 (ส่วนใหญ่ 15/20 วัน)")
- ปัดทศนิยม 2 ตำแหน่งที่ผลลัพธ์ (`round2_`)

## ขอบเขตที่ระบบนี้ **ไม่ได้ทำ** (ยังไม่ได้ทดสอบ — ห้ามอ้างว่ามี)
- **ประกันสังคม** ไม่คำนวณอัตโนมัติ
- **ภาษีเงินได้ ภ.ง.ด.1** ไม่คำนวณแบบรายปีตามขั้นบันได — `wht` เป็นช่องกรอกเองต่อคนต่องวด
- เงินเดือนประจำรายเดือน (ไม่ใช่รายชั่วโมง) · ขาด/ลา/สาย หักเงิน · OT วันหยุด (×2/×3) — ยังไม่มี
ถ้าลูกค้าต้องการข้อไหน ต้องออกแบบเพิ่มและยืนยันอัตรากับผู้ใช้/ผู้เชี่ยวชาญบัญชีก่อน ห้ามเดาอัตรา
ลงบัญชีตอนจ่ายเงินเดือน (Dr เงินเดือน / Cr เงินสด + ภ.ง.ด.1 ค้างจ่าย + ประกันสังคมค้างจ่าย) เป็นงานของฝั่งบัญชี

## คำเตือนที่ต้องโชว์ในหน้าตรวจเวลา (ห้ามแก้ค่าให้เองเงียบๆ)
| คำเตือน | เงื่อนไข |
|---|---|
| ชั่วโมงเกิน 16 | normal+ot > 16 |
| เวลาออก ≤ เวลาเข้า | อ่านเวลาสลับ/ข้ามเที่ยงคืน |
| ไม่พบรหัสพนักงาน | รหัสไม่อยู่ใน Employees |
| วันซ้ำ | คน+วันเดียวกันมี > 1 แถว (ส่งรูปซ้ำ) |
| ยังไม่ตั้งค่าแรง | hourly_rate ≤ 0 |
| วันที่ล่วงหน้า | work_date > วันนี้ = OCR อ่านวัน/เดือนพลาด — **ไม่เดาวันที่ถูกให้** ให้คนตรวจตัดสิน |
