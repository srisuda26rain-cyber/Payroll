# สลิปเงินเดือน / ทะเบียนเงินได้ เป็น PDF

## ข้อสรุป (พิสูจน์ด้วยภาพจริง)
`Utilities.newBlob(html,'text/html').getAs('application/pdf')` **ไม่วาดพื้นสีของ cell เลย** ไม่ว่าจะเขียนแบบ
bgcolor / inline style / th / tr / div / span — เหลือแค่เส้นขอบกับสีตัวอักษร
**ห้ามตรวจด้วยการ grep สีในไฟล์ PDF** — สีเส้นขอบถูกวาดเป็น fill rect หลอกให้คิดว่าพื้นสีมาแล้ว ต้องแปลงเป็นภาพแล้วดูด้วยตา

**ทางที่ใช้จริง**: สร้าง PDF ในเบราว์เซอร์ → `loadPdfLibs` + `slipPdfBlob` / `regPdfBlob` / `tsPdfBlob` ใน `assets/template/Index.html`
1. วาด HTML สลิปลงกล่องนอกจอ (`left:-99999px`, กว้าง 1400px)
2. **รอฟอนต์ไทยโหลดครบ** (`tsFontsReady` / `document.fonts.ready`) — ไม่งั้น html2canvas วาดด้วยฟอนต์สำรอง
3. `html2canvas(el, {scale:2, backgroundColor:'#fff'})` → JPEG 0.92 → `jsPDF` A4 หน้า/คน ย่อให้พอดีหน้า
4. ดาวน์โหลดให้ผู้ใช้ + ส่ง base64 ไป `apiSaveReportPdf(name, b64, '05_Payslips')` เก็บสำเนา
- html2canvas **วาด CSS `zoom` ไม่ถูก** → จับภาพที่ขนาดจริงแล้วค่อยย่อตอนวางลง PDF
- โลโก้มาจาก `STATE.logo` (data URI ที่ผู้ใช้อัปโหลด ส่งมากับ apiBootstrap) — ไม่โหลดรูปจาก URL ภายนอก html2canvas จะติด CORS

## เนื้อหาสลิปที่ใช้งานจริง
หัว: โลโก้ ชื่อบริษัท (ไทย/อังกฤษ) ที่อยู่ เลขผู้เสียภาษี · เลขที่สลิป `SLIP-yyMM-0001` · งวด (วันที่ไทย พ.ศ.) · วันที่จ่าย
พนักงาน: รหัส ชื่อ ตำแหน่ง แผนก เลขบัตร ธนาคาร/เลขบัญชี · **เวลาทำงาน** (`work_time` ช่วงที่ทำบ่อยสุด — ผู้ใช้ขอแทน "วันเริ่มงาน")
รายได้: ชม.ปกติ × อัตรา · OT × อัตรา · เบี้ยขยัน · เงินเพิ่ม · โบนัส → รวมรายได้
รายการหัก: ภาษีหัก ณ ที่จ่าย · หักอื่น → รวมหัก · **เงินได้สุทธิ** · หมายเหตุท้ายสลิป
- ค่าว่าง (ที่อยู่/เลขภาษีที่ลูกค้ายังไม่ให้) → **ซ่อนบรรทัด** ห้ามเดาใส่
- ออกสลิปก่อนอนุมัติครบ → แปะแถบ "ฉบับร่าง"

## ความปลอดภัยของไฟล์ (เว็บ anonymous + รันสิทธิ์เจ้าของ)
- `apiSaveReportPdf`: ต้องขึ้นต้น `%PDF` · บังคับนามสกุล .pdf · จำกัดขนาด · โฟลเดอร์ปลายทาง whitelist
  (ไม่งั้นใครก็ฝากไฟล์อะไรไว้ใน 05_Payslips แล้วบอทหยิบไปส่งพนักงานเป็น "สลิปจริง")
- หน้า "ประวัติสลิป": ส่งไฟล์กลับเป็น **base64** ไม่ส่งลิงก์ Drive (คนดูไม่มีสิทธิ์ → เจอหน้า Google Sign in)
- `apiPayslipFile(fileId)` **ต้องเช็คว่าอยู่ใน 05_Payslips** ทุกครั้ง — ไม่งั้นเดา file id แล้วดูดไฟล์อื่นในไดรฟ์เจ้าของได้
- ออกสลิปซ้ำ = Drive สร้างไฟล์ชื่อซ้ำอีกใบ ไม่ทับของเดิม
