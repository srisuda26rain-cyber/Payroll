# โหมดสอน: พาผู้เรียนสร้างระบบเงินเดือนเองทีละขั้น

วิธีสอนที่เร็วที่สุด: ให้ผู้เรียนติดตั้ง `assets/template/` ก่อน (ตั้งชื่อบริษัท+อัปโลโก้ของตัวเอง) แล้วใช้ตารางนี้พาอ่านทีละส่วนว่าทำงานยังไง
หรือสร้างใหม่ทีละบทโดยเปิดเทมเพลตเป็นเฉลย

ผู้เรียนเป้าหมาย: นักบัญชี/HR ที่ไม่ใช่โปรแกรมเมอร์ ใช้ Claude ช่วยเขียนโค้ด
หลักการ: **ทุกบทต้องจบด้วยของที่เปิดดูได้จริง** ไม่อธิบายทฤษฎียาวก่อนลงมือ · ใช้ข้อมูลสมมติเท่านั้น

| บท | เป้าหมายที่ต้องเห็นกับตา | ของที่ใช้ | จุดที่ผู้เรียนมักพลาด |
|---|---|---|---|
| 1. ออกแบบข้อมูล | ชีต Employees / Attendance / Settings พร้อมหัวคอลัมน์ | ตารางชีตใน `architecture.md` | อยากใส่ทุกอย่างในชีตเดียว · แทรกคอลัมน์กลางภายหลัง |
| 2. Apps Script แรก | กด Run `setup()` แล้วได้ชีต+โฟลเดอร์ใน Drive | `assets/template/Code.gs` ส่วน Init | ลืมกดอนุญาตสิทธิ์ · ชื่อโฟลเดอร์ซ้ำระบบอื่น |
| 3. สูตรคำนวณ | กรอกเวลา 09:00–18:30 แล้วได้ ปกติ 8 / OT 0.5 | `calcRowHours_` + `calcPayroll_` | พัก 0 ยังหัก 60 · เวลาจากชีตกลายเป็น Date |
| 4. หน้าเว็บ | เปิดลิงก์ /exec เห็นตารางเวลาพร้อมคำเตือน | `doGet` + Index.html + `apiAttendance` | Date object ทำให้ได้ null · ไม่ JSON.parse |
| 5. ตรวจ-อนุมัติ | ปุ่มอนุมัติ → คำนวณเฉพาะแถวอนุมัติ | `onlyApproved` | คำนวณก่อนตรวจ = จ่ายเงินผิด |
| 6. ปรับเงิน | เบี้ยขยัน/โบนัส/หัก ต่อคนต่องวด | ชีต Adjustments | เปลี่ยนช่วงงวดแล้วยอดปรับหาย (key ต้องตรงเป๊ะ) |
| 7. สลิป PDF | ดาวน์โหลดสลิปสีสวย + สำเนาใน Drive | `slipPdfBlob` ใน Index.html + `apiSaveReportPdf` | ใช้ getAs('application/pdf') แล้วสีหาย |
| 8. Deploy | อัปเดตแล้ว URL เดิมยังใช้ได้ | `deploy-and-test.md` | deploy ไม่ใส่ `-i` ได้ URL ใหม่ · push ไฟล์ไม่ครบ |
| 9. (เสริม) AI อ่านใบลงเวลา | ถ่ายรูปใบลงเวลา → ได้แถวให้ตรวจแก้ | `timesheet-ocr-line.md` | ให้ AI อ่านช่อง OT · ไม่เก็บรูปก่อนเรียก AI |
| 10. (เสริม) ความปลอดภัย | อธิบายได้ว่าทำไมห้ามส่งลิงก์ Drive/ห้ามรับรหัสพนักงานจากภายนอก | ส่วนความปลอดภัยในแต่ละไฟล์ | คิดว่า "ลิงก์ไม่มีใครรู้" = ปลอดภัย |

## แบบฝึกหัดตรวจความเข้าใจ (มีเฉลยจากเทสจริง)
1. ค่าแรง 80 บาท/ชม. ไม่ได้ตั้ง OT เอง ทำ 09:00–18:30 สองวัน กับ 09:00–18:00 หนึ่งวัน → ได้เท่าไร?
   เฉลย: ปกติ 24 ชม. × 80 = 1,920 · OT 1 ชม. × 120 = 120 · รวม 2,040
2. ตั้ง `ot_min_minutes = 30` แล้วทำเกิน 30 นาทีพอดี นับ OT ไหม? → **นับ** (30 ≥ 30) ต้องตั้ง 60 ถึงจะไม่นับ
3. ทำงานครึ่งวัน 08:00–12:00 ไม่พัก ใส่พัก 0 ได้กี่ชั่วโมง? → **3** (0 = ใช้ค่าตั้งต้น 60) ต้องกรอกชั่วโมงปกติเป็น 4 เอง

รันยืนยันเฉลยข้อ 2–3 ได้ด้วย `node scripts/test-core.js`
